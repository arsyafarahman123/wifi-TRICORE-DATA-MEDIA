Cadangan data titik ODP (dipakai kalau server gagal mengambil langsung dari Google My Maps).

Cara membuat odp.kml:
1. Buka peta di Google My Maps -> klik titik tiga di sebelah judul peta -> "Ekspor ke KML/KMZ".
2. Pilih "Seluruh peta" dan CENTANG "Ekspor sebagai KML, bukan KMZ".
3. Ganti nama file hasilnya menjadi odp.kml lalu taruh di folder ini (public/data/).
